# Physics Engine (From Scratch)

This repository contains a custom 2D physics engine developed from scratch in C++ as part of my Software Engineering degree at Loyola Andalusia University.

The goal of this project was to deeply understand how modern game engines work internally by implementing core systems such as rendering, physics simulation, and game architecture without relying on external engines.

---

## Overview

This project explores the fundamentals behind physics simulation engines, including:

- Game loop design (frame-independent updates)
- Vector mathematics and kinematics
- Collision detection and response
- Rendering primitives and low-level graphics
- Engine architecture and modular design

The engine is built using C++17 and SDL2, focusing on performance and low-level control.

---

## Architecture

The engine follows a modular architecture inspired by real-world game engines:

- Core Engine (Game loop, Delta time)
- Physics System (Forces, motion, rigid bodies)
- Math Module (Custom vector library)
- Rendering System (Pixel buffer, primitives)
- Utilities (Logging, input)

---

## Features

- Game Loop with delta time (frame-independent)
- Custom 2D Vector Library
- Basic Physics Simulation
- Collision Detection
- Low-level Rendering System
